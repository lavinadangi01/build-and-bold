# Vibrant Creator Hub

create a high-converting, visually stunning, modern personal portfolio website for a 20-year-old 1st-year B.Tech Computer Science Engineering student at JECRC University, Jaipur. The website should highlight early industry experience, technical skills, creative shopify/marketing accomplishments, and an ambitious startup concept.

🎨 Theme, Styling & Aesthetic Reference
Inspiration Reference: Based on Vanya Issar's Portfolio, featuring clean typography, high visual impact, creative layouts, interactive elements, and personal branding.
Color Palette: Creative, energetic, and professional dynamic theme. High-contrast dark mode foundation (e.g., Deep Midnight Blue/Charcoal #0B0F19) mixed with vibrant accent gradients (e.g., Electric Violet, Neon Cyan, and Coral Sunset).
Typography: Bold sans-serif headers (e.g., Syne, Clash Display, or Plus Jakarta Sans) paired with clean body text (e.g., Inter or DMSans).
Animations & Interactivity: Smooth parallax scrolling, hover glow effects on buttons/cards, scroll-triggered fade-ins/slide-ups, subtle animated background particle grid, dynamic micro-interactions, and animated tech stack icons.
